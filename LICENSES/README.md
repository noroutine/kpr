# License bundle

What ships inside the kpr image besides kpr itself (GPLv3,
[/LICENSE](/LICENSE)), and where its attributions live.

## Contents

- [Apache-2.0.txt](Apache-2.0.txt) — canonical Apache-2.0 text,
  covering the stock `registry` binary and every Apache-2.0 Go
  module in the link set.
- `THIRD-PARTY.md` — generated by `scripts/licenses.sh`
  (`make licenses`), never edited by hand: the module table plus
  MIT/BSD notices in full. Regenerated on every image build, so
  it always matches the linked set. Refuses (non-zero exit) on
  any missing or non-permissive license — a copyleft dependency
  breaks the build instead of sliding in.

## Provenance

- `/bin/registry` is copied verbatim from the `registry:3`
  image (`distribution/distribution`, Apache-2.0) and exec'd as
  a subprocess — aggregation, not linking. Kept version-pinned
  with the registry service in compose by construction (see
  `Dockerfile.package`).
- Alpine userland (`busybox`, `apk-tools`: GPLv2-only) and the
  apk adds (`bash`, `wget`: GPLv3; `ca-certificates`: MPL data;
  `tzdata`: public domain) are separate programs aggregated in
  the image. Their notices ride their packages upstream.
- The image carries this bundle at `/app/licenses/`
  (`kpr-GPLv3.txt` plus this directory).
