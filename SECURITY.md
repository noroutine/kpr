# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| `master` (latest) | yes |
| anything older | no — upgrade first, then report |

## Reporting a vulnerability

Open a GitHub issue titled `security: <short description>` with impact and
reproduction. There is no private channel: assume everything you send is
public, so omit secrets and live credentials from the report.
