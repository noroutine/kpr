Push. Pull.
Forget.

Tag any image with a TTL and it expires on its own — stale uploads and vanished tags get swept too. No account, no cleanup cron. Your registry, your disk back.

$ docker tag my-app:build my-registry:5000/my-app:10m
$ docker push my-registry:5000/my-app:10m
# …10 minutes later, it's gone. Like magic.

What kpr does

  • receiver tracks every push as a redis row
  • reap marks expired rows due, with a reason
  • sweep deletes marked manifests by digest
  • offline make gc reclaims the orphaned blobs
